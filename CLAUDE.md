# SR Proceso Millonario — Sistema de Lead Magnets

Este repo es el sistema de captación de SR Growth Agency.
No es un proyecto de código: es una **base de conocimiento operativa**.
Cada archivo acá existe para producir un resultado concreto: captar la
atención de un prospecto, darle valor real, y llevarlo a una llamada.

## Cómo leer este repo

| Carpeta | Qué contiene |
|---|---|
| `marca/` | Quién soy, cómo hablo, a quién le vendo, qué vendo |
| `referentes/` | Info de referentes, ya traducida a mi comunicación |
| `lead-magnets/` | Cada herramienta de captación, completa y lista para usar |
| `embudo/` | El camino del comentario a la llamada agendada |

**Antes de trabajar en cualquier lead magnet, lee primero:**
1. `marca/voz-y-tono.md` — no negociable, define cómo se escribe todo
2. `marca/icp.md` — a quién le estamos hablando
3. `lead-magnets/catalogo.md` — qué existe y en qué estado está

## Reglas del sistema

**1. Todo se adapta a mi comunicación.**
La info de referentes viene de muchas nacionalidades. Nunca se copia el
modismo del referente. Se extrae el **mecanismo** (por qué funciona) y se
reescribe en español neutro. Ver `marca/voz-y-tono.md`.

**2. Cada lead magnet da valor real antes de pedir algo.**
La persona tiene que sentir que ya recibió algo que vale, incluso si nunca
compra. Si el análisis es genérico, no sirve. Si no se puede ser específico,
no se entrega.

**3. El valor gratis resuelve el "qué". El servicio resuelve el "cómo sostenerlo".**
El lead magnet nombra los problemas con precisión y regala 2 acciones
aplicables hoy. Lo que queda afuera no es información escondida: es la
ejecución sostenida, que es exactamente lo que se vende. Nunca se miente
diciendo "hay algo que no te puedo decir".

**4. Un lead magnet no está listo hasta que tenga sus 4 piezas.**
- `metodologia.md` — el criterio de análisis
- `motor.md` — el prompt que ejecuta el análisis
- `entregable.md` — el formato de lo que recibe la persona
- `captacion.md` — el contenido que lo promociona + el DM

**5. Cada lead magnet terminado se convierte en skill.**
Cuando la metodología está probada, se empaqueta como skill para que
funcione con un comando desde cualquier chat. Es la diferencia entre tener
documentos y tener herramientas.
