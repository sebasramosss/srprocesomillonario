# SR Proceso Millonario — Sistema de Lead Magnets

Este repo es el sistema de captación de SR Growth Agency.
No es un proyecto de código: es una **base de conocimiento operativa**.
Cada archivo acá existe para producir un resultado concreto: captar la
atención de un prospecto, darle valor real, y llevarlo a una llamada.

## Cómo leer este repo

| Carpeta | Qué contiene |
|---|---|
| `diseno/` | El sistema de diseño. Gobierna TODO lo visual |
| `marca/` | Quién soy, cómo hablo, a quién le vendo, qué vendo |
| `nichos/` | El motor: el criterio, los 7 ganchos universales y lo que funcionó por nicho |
| `referentes/` | Info de referentes, ya traducida a mi comunicación |
| `lead-magnets/` | Cada herramienta de captación, completa y lista para usar |
| `embudo/` | El camino del comentario a la llamada agendada |

**Antes de trabajar en cualquier lead magnet, lee primero:**
1. `diseno/README.md` + `diseno/modos.md` — no negociable para todo lo visual
2. `marca/voz-y-tono.md` — no negociable, define cómo se escribe todo
3. `marca/sebas.md` — cómo pienso y cómo enseño, para que todo suene a mí
4. `nichos/README.md` — el criterio de sector / nicho / micro nicho
5. `nichos/cta.md` — el hallazgo más grande: el regalo contra la llamada
6. `nichos/ganchos.md` — los ganchos medidos en 119 videos
7. `nichos/catalogo.md` — lo que ya funcionó en cada nicho, con números
8. `marca/icp.md` — a quién le estamos hablando
9. `lead-magnets/catalogo.md` — qué existe y en qué estado está

## Reglas del sistema

**REGLA MADRE — Nada se inventa.**

Todo lo que se le muestra a un prospecto sale de material real de SRGA:
guiones grabados, métricas medidas, frases dichas en una llamada, casos
con nombre y número.

- Si no tiene fuente, **no se escribe**.
- Si hace falta un ejemplo y no existe, **se pide**, no se inventa.
- Cada dato lleva de dónde salió: documento, cliente y fecha.
- Un ejemplo de demostración se marca como demostración, siempre y de
  forma visible.

Dentro del repo puede haber propuestas sin grabar, pero van marcadas como
tales y **nunca** se presentan a un prospecto como «esto nos funcionó».

*Esta regla la fijó Sebastián el 7 oct 2026, después de que una frase
inventada se colara a un entregable como si fuera una línea real de un
guion.*

**0. Todo lo visual sigue el sistema de diseño.**
`diseno/` gobierna landing, presentación, masterclass, módulo, PDF, página
de coaching y checkout. Dos modos: BLACK para poder y autoridad, LIGHT para
claridad y sistema. Naranja `#FF802E` nunca pasa del 10% de la composición.
Antes de diseñar cualquier sección: **¿cuál es UNA imagen que hace visible
esta idea?** Dirección de arte, no solo UI.

**1. Todo se adapta a mi comunicación.**
La info de referentes viene de muchas nacionalidades. Nunca se copia el
modismo del referente. Se extrae el **mecanismo** (por qué funciona) y se
reescribe en español neutro. Ver `marca/voz-y-tono.md`.

**2. Cada lead magnet da valor real antes de pedir algo.**
La persona tiene que sentir que ya recibió algo que vale, incluso si nunca
compra. Si el análisis es genérico, no sirve. Si no se puede ser específico,
no se entrega.

**3. El valor gratis resuelve el "qué". El servicio resuelve el "cómo sostenerlo".**
El lead magnet nombra los problemas con precisión y regala 2 acciones
aplicables hoy. Lo que queda afuera no es información escondida: es la
ejecución sostenida, que es exactamente lo que se vende. Nunca se miente
diciendo "hay algo que no te puedo decir".

**4. Un lead magnet no está listo hasta que tenga sus 4 piezas.**
- `metodologia.md` — el criterio de análisis
- `motor.md` — el prompt que ejecuta el análisis
- `entregable.md` — el formato de lo que recibe la persona
- `captacion.md` — el contenido que lo promociona + el DM

**5. Las llamadas se analizan de forma continua.**
De cada sesión en adelante se revisan las llamadas nuevas de Fathom
(masterclasses, 1:1, ventas) y lo que aporte algo se incorpora a
`marca/sebas.md`, `nichos/` o al embudo. El cerebro no se escribe una vez:
se actualiza con cada llamada.

**6. Cada lead magnet terminado se convierte en skill.**
Cuando la metodología está probada, se empaqueta como skill para que
funcione con un comando desde cualquier chat. Es la diferencia entre tener
documentos y tener herramientas.

## El foco (decidido 7 oct 2026)

**Todos los lead magnets son para la marca personal y el coaching.
No para la agencia.**

- **A quién:** personas que ya tienen un producto o servicio y quieren
  llevar su marca personal a $5-10K al mes
- **Hacia dónde:** la Academia — Proceso Millonario ($1,200/6m, $2,000/año)
  y Millonario VIP ($3,000/6m, $5,000/año)
- **El mensaje siempre gira alrededor de la mentalidad**

El material de la agencia (`marca/oferta.md` sección consultoría,
`marca/mecanismo.md`) se conserva porque la metodología es la misma y
eventualmente se usará. Pero el diagnóstico apunta al coaching.
