# Sistema de Diseño SR

> **Fuente:** brief de identidad visual de Sebastián, 7 oct 2026.
> **Regla:** esto gobierna TODO lo visual — landing, presentación,
> masterclass, módulo de la Academia, PDF, página de coaching, checkout.
> Todo tiene que sentirse del mismo universo.

## El concepto

La estética comunica: **ambición · disciplina · crecimiento · autoridad ·
transformación · dinero · claridad.**

Referencia conceptual: **Apple** (minimalismo, espacio, producto premium)
× **Nike** (energía, mentalidad ganadora) × coaching premium (autoridad y
alto valor) × marca personal moderna (humana, aspiracional) × tecnología
(interfaces limpias, funnels, gráficos).

### Lo que nunca
- Estética de «curso online barato»
- Diseños saturados
- Genéricos de Canva
- Exceso de degradados, iconos, tarjetas o efectos
- Gaming, crypto, casino, dropshipping, neón futurista
- Emojis grandes como elemento de diseño
- Fotografía stock genérica

## Color

| Rol | Hex |
|---|---|
| **Naranja de marca** | `#FF802E` |
| Negro | `#050505` · `#0A0A0A` |
| Blanco | `#FFFFFF` |
| Grises | `#F5F5F5` · `#EAEAEA` · `#A0A0A0` · `#222222` |

**La proporción no se negocia:**
**70-80% base + 15-20% neutros + 5-10% naranja.**

El naranja solo como: punto focal, CTA, palabra destacada, línea, número,
icono, glow sutil, progreso, o conexión dentro de un diagrama.
Nunca llenar la interfaz de naranja.

---

## Tipografía

Helvetica / Helvetica Neue / **Montserrat** / sans-serif moderna.

- **Títulos:** grandes, bold, muy limpios, pocas palabras, fuerte contraste
- **Subtítulos:** medium/semibold, fáciles de escanear
- **Texto:** regular, espaciado generoso, párrafos cortos

La jerarquía se siente **editorial**. La palabra estratégica puede ir en
naranja. No abusar de MAYÚSCULAS en textos largos.

```
CREA UNA MARCA
QUE LA GENTE
RECUERDE.
```

---

## Composición

**Muchísimo espacio negativo.** Cada sección tiene **una** idea principal.
No llenar la pantalla porque hay espacio.

Estructura ideal:
1. Headline fuerte
2. Mensaje complementario corto
3. Visual que explique o refuerce el concepto
4. CTA o conclusión

**Evitar 6 tarjetas cuando una sola composición visual comunica la idea.**

---

## Regla fundamental

Antes de diseñar cada sección:

> **«¿Cuál es UNA imagen que puede hacer visible esta idea?»**

Construir primero ese concepto visual. Después integrar el copy.
No convertir cada sección en título + párrafo + tres tarjetas.

**Dirección de arte, no solo UI.**

## Metáforas visuales

| Concepto | Visual |
|---|---|
| Crecimiento | Gráfica ascendente minimalista |
| Marca personal | Silueta central conectada con audiencia |
| Contenido | Smartphone + Reels/TikTok/Instagram |
| Viralidad | Contenido expandiéndose a miles |
| Ventas | Funnel visual |
| Leads | Personas entrando al funnel |
| Conversión | Lead → llamada → cliente → pago |
| Disciplina | Calendario / streak / checkmarks / progreso |
| Identidad | Persona → mensaje → percepción → comunidad |
| Oferta | Producto central rodeado de valor |
| Sistema | Nodos conectados |
| Transformación | Estado A → proceso → estado B |
| Comunidad | Grupo orbitando una identidad central |
| Dinero | Números, gráficas, transacciones abstractas — **nunca billetes volando** |

## Iconos

Minimalistas, outline, geométricos, modernos, **consistentes**.
Stroke fino o medio. Blanco sobre negro, negro sobre blanco, naranja solo
para destacar. **Nunca mezclar estilos de iconos en una misma página.**

Progresión con relleno:
```
○ IDEA  →  ○ CONTENIDO  →  ● AUDIENCIA  →  ● VENTA
```
El naranja muestra progresión o importancia.

---

## Diagramas

**Uno de los elementos más importantes de la identidad.**

Simples · grandes · fáciles de comprender · **máximo 3-5 pasos visibles** ·
conexiones muy claras. Nodos blancos o negros, naranja para el flujo.

```
CONTENIDO → ATENCIÓN → CONFIANZA → LEADS → VENTAS
```

---

## Números y métricas

Cuando una métrica importa, **es protagonista**. El número ocupa entre
**25% y 40%** de la composición. Nunca esconder un dato importante en una
tarjeta chica.

```
36M        +100K          $20K
VIEWS      FOLLOWERS      MONTH
```

---

## Interfaces y mockups

Instagram, TikTok, YouTube, WhatsApp, CRM, calendario, analytics —
**simplificadas**. Solo la información necesaria para comunicar el concepto.

```
VIDEO → 1.2M views → 2,430 leads → 87 calls → 21 clients
```

---

## Elementos 3D

Selectivos, para elevar: smartphone flotante, ventanas de Instagram,
gráfica, tarjetas, play button, rayo, esfera, interfaz, bloques, flechas,
funnel.

Estilo **Apple product visualization**: limpio, realista, premium,
iluminación suave. Sin parecer videojuego.

---

## Fotografía de marca personal

- **No** modificar rasgos faciales
- **No** suavizar excesivamente la piel
- **No** que parezca generada por IA
- Mantener textura natural

Sí: recorte limpio, fondo removido, iluminación cinematográfica suave,
sombras, profundidad, composición editorial.

**La persona debe sentirse integrada en el diseño, no pegada encima.**

---

## Elementos recurrentes

**SR⚡** — el rayo representa acción, energía, velocidad, ejecución.
Siempre discreto.

También: líneas, coordenadas, puntos, flechas pequeñas, grids muy sutiles,
números enormes, barras de progreso, círculos, interfaces flotantes.
Siempre minimalistas.

---

## La experiencia

La persona debe sentir:

> «Esto es premium.»
> «Esta persona tiene un sistema.»
> «Esto está organizado.»
> «Quiero llegar al siguiente nivel.»
> «Esto se siente diferente a otro curso de redes sociales.»

El diseño transmite **ANTES → PROCESO → DESPUÉS.**
