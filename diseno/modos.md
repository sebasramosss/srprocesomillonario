# Los dos modos

Toda pieza se construye en uno de los dos. Se puede alternar dentro de una
misma pieza, pero con intención: el modo marca el registro emocional.

| | **BLACK MODE** | **LIGHT MODE** |
|---|---|---|
| Transmite | Poder, autoridad, exclusividad, ambición, transformación | Claridad, conocimiento, sistema, estrategia, profesionalismo |
| Se siente como | Apple keynote dark × Nike campaign × startup premium | Apple.com × editorial premium × consulting deck |
| Se usa en | Hero, manifiesto, oferta, cierre, momento de mentalidad | Diagnóstico, metodología, datos, explicación de sistema |

---

## BLACK MODE

**Fondo:** `#050505` · `#080808` · `#0A0A0A`
Evitar negro completamente plano: textura imperceptible o gradiente radial
extremadamente sutil.

**Texto:** headline `#FFFFFF` · secundario `#AFAFAF` · terciario `#777777`
**Accent:** `#FF802E`

Mucho espacio negro. Tipografía blanca enorme. **Una palabra naranja.**
Visuales flotando en profundidad.

```
BUILD A BRAND
THAT PEOPLE
REMEMBER.
```

**Iluminación:** fondo oscuro, rim light naranja muy sutil, reflejos
blancos, sombras suaves, highlights limpios.
**Nunca un glow naranja exagerado.** Elegante y cinematográfico.

**Cards** (solo si hacen falta): fondo `#111111`, borde `1px #242424`,
radius 16-24px. Nada de sombras enormes. Una línea naranja fina puede
indicar selección.

**Funciona especialmente bien con:** teléfonos 3D, interfaces flotantes,
funnels, métricas, gráficas, mapas conceptuales, números enormes,
fotografías recortadas, timelines, diagramas, antes/después.

### Composiciones
- **HERO EDITORIAL** — texto grande izquierda, persona o visual derecha
- **HERO CENTRAL** — headline enorme centrado, visual debajo
- **DATA MOMENT** — número enorme ocupando gran parte de la pantalla
- **DIAGRAM MOMENT** — visual central, 3-5 nodos, conexiones naranjas
- **QUOTE / PRINCIPLE** — fondo casi negro, una frase enorme, una palabra
  naranja, nada más

**Sensación final:** premium, ambicioso, masculino sin ser agresivo,
moderno, tecnológico, limpio, cinematográfico, high-ticket.

## LIGHT MODE

**Fondo:** `#FFFFFF` principal · `#F7F7F7` y `#F3F3F3` secundarios
**Texto:** `#090909` · secundario `#666666`
**Accent:** `#FF802E`

**El blanco no significa llenar todo con tarjetas.** Muchísimo espacio
vacío. Dejar respirar.

El contraste viene de **tipografía, escala, composición, imagen y naranja**.
Nunca de añadir decoración.

**Elementos:** líneas negras finas, diagramas, tipografía grande, números,
flechas, formas geométricas, smartphones, gráficas, mockups, fotografías
recortadas, naranja puntual.

**Iconos:** principalmente negros. El elemento activo o importante en
naranja.

```
○ IDEA  →  ○ CONTENIDO  →  ● AUDIENCIA  →  ● VENTA
```

**Cards:** fondo `#FFFFFF` con borde `#E7E7E7`, o fondo `#F7F7F7` sin
borde. Radius 16-24px. Nunca demasiadas.

**3D:** objetos sobre blanco, sombras extremadamente suaves, materiales
blancos, detalles negros, accent naranja. Referencia: páginas de producto
de Apple.

**Fotografía:** recortes limpios sobre blanco, sombra muy ligera detrás de
la persona para dar profundidad. Elementos naranjas alrededor como
información gráfica, nunca decoración aleatoria.

**Gráficas:** negro y gris para datos normales. Naranja solo para el
resultado principal, el crecimiento, el punto seleccionado, el objetivo o
la conversión.

### Composición editorial

```
01

CONSTRUYE
UNA MARCA QUE
VENDA.

[visual conceptual]

Explicación de máximo 2-3 líneas.
```

**Sensación final:** inteligente, limpia, premium, ordenada, estratégica,
moderna, educativa. Una marca que domina su metodología — no una
presentación corporativa aburrida.
